# Japan Autumn Trip 2026 — Trip Member Guide

คู่มือเว็บแอปสำหรับทริป 9–17 ต.ค. 2569

## Run locally

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000`

## Deploy ฟรี

โปรเจกต์นี้เหมาะกับ Vercel / Netlify / Cloudflare Pages ที่รองรับ Next.js

1. แตก ZIP แล้วอัปโหลดเข้า GitHub
2. Import repository เข้า Vercel
3. Deploy ได้เลย — ไม่มี environment variable ที่จำเป็น

## ข้อมูลสด

- Weather: Open-Meteo API ดึงพยากรณ์ 9–17 ต.ค. 2026 ฝั่ง browser
- Autumn leaves: snapshot จากแหล่งข้อมูลวันที่ 1–2 ต.ค. 2026 และมีลิงก์ไปยังแหล่งข้อมูลล่าสุด
- Live cameras: ลิงก์ทางการตามรายการที่ผู้ใช้ให้มา

## หมายเหตุเรื่องรูปภาพ

รูปภาพบางใบเป็น remote images จากเว็บไซต์ท่องเที่ยว/สื่อที่ใช้เพื่อประกอบคู่มือ พร้อมลิงก์ไปยังแหล่งข้อมูล/เว็บไซต์ต้นทาง ควรตรวจสอบสิทธิ์การใช้งานหากนำเว็บไปเผยแพร่เชิงพาณิชย์
